Privacy policy

Metis is a private personal assistant operated by Tim Kok. This website explains the project; it does not offer public account registration.

Last updated: 28 September 2026

Information Metis accesses

Features are connected with the account owner's permission. Depending on the enabled features, Metis processes conversations with the assistant, tasks, reminders, preferences, calendar details, device identifiers and push tokens, location, and selected Apple Health information.

The Gmail appointment integration requests only Gmail read-only access. It reads message identifiers, thread identifiers, sender and subject information, timestamps, message text and text calendar attachments to identify confirmed appointments, changes and cancellations. Monitoring begins when the connection is activated; it does not import the previous mailbox history. It does not send, edit or delete Gmail messages.

The optional WhatsApp integration receives new text messages from chats selected by the owner through a linked device. The current personal setup includes all chats. It uses an unofficial integration and is not affiliated with WhatsApp or Meta. It does not send replies, mark conversations read, or transcribe voice notes, images or video.

Why the information is used

Metis uses this information to provide the owner's visible assistant features: answering requests, organizing reminders and priorities, finding appointment proposals, checking possible calendar conflicts, and sending relevant notifications. For new WhatsApp plans, it looks for the owner's agreement to attend. A proposal is not a calendar booking: the owner must review and approve each change in the iPhone app.

AI processing and other providers

With the owner's authorization, message text, relevant conversation excerpts and appointment context are sent to the OpenAI API to identify and explain proposed calendar changes. Assistant requests may also include relevant information from enabled features. Appointment extraction requests disable OpenAI response storage with store=False; this does not mean that the provider has no separate security or abuse-monitoring retention. OpenAI's own service terms and data policies also apply.

Data is stored on the owner's private Metis server and on the paired device as needed. Google provides Gmail access. Apple delivers push notifications and provides the iPhone calendar interface. Public pages on this website are hosted by GitHub Pages; private messages, credentials, health records and the application database are not published here. These providers process information needed to supply their respective services.

Metis does not sell personal data or use Google user data for advertising, data brokerage, credit decisions or training general-purpose AI models. Google user data is used and transferred only to provide the authorized user-facing features. Metis's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

Processed raw email and WhatsApp conversation context in the appointment system is removed after seven days. Unprocessed messages are retained while awaiting retries. Excerpts supporting proposals, approval records and calendar receipts remain with the appointment records until removed. Other assistant records are retained for the configured features until deleted by the owner or administrator. Server backups may retain earlier copies until those backups are rotated or removed.

Account credentials are stored outside the application's source repository with restricted filesystem access. The paired app uses authenticated access to the private server. Access is restricted to the owner and explicitly authorized administration or troubleshooting. No system can guarantee absolute security.

Control, revocation and deletion

The owner can revoke Gmail access through Google Account connections, unlink the receiver through WhatsApp's Linked Devices settings, and change Calendar, Health and Location permissions in iPhone Settings. Revoking a connection stops future access; it does not automatically delete previously stored records or existing calendar events.

To request removal of stored Metis information, contact the operator using the address below. Health data also has an explicit deletion control in the backend. Calendar events can be removed in Apple Calendar. Data deletion requests can include stored proposals and message excerpts; backups are addressed separately as described above.

This public website

These pages do not add analytics, advertising scripts or tracking cookies. GitHub may process ordinary hosting request information under its privacy statement. Links to other providers lead to their own services and policies.

Changes and contact

This page will be updated when data practices change. New data sources or materially different uses require the owner's authorization. Questions or deletion requests can be sent to Tim Kok at koktim2003@gmail.com.
